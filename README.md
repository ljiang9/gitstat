# gitstat

仓库活跃度一览：谁提交了多少、什么时候提交。

纯 Python 标准库，只**读** git 历史，不修改仓库任何东西。

## 安装

```bash
cd gitstat
python3 -m gitstat
```

## 用法

```bash
gitstat                          # 在某个 git 仓库里运行
gitstat --since "3 months ago"   # 只看近三个月
gitstat --since 2026-01-01
gitstat --author "张三"           # 只看某作者（git --author 语法）
gitstat --json                   # 机器可读输出
```

## 诚实说明

- 数据来自 `git log --numstat`，文件改名在统计里会表现为"删 + 增"两行（这是 git diff 本身的记法，不是 bug）。
- 二进制文件的插入/删除行数记为 0（numstat 里显示为 `-`）。
- 默认排除 merge 提交（`--no-merges`）。
- 小时分布按**本地时区**解析提交时间戳。

## 已知局限

- 需要本地有 git 且在仓库目录里运行。
- 超大仓库（几十万提交）首次扫描会慢，因为要走完整个 log。
